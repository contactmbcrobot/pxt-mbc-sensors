# line width

Number of channels on the line (line width); 0 = no line.

```sig
mbc.lineWidth()
```

## Returns

* a number.

## Example

```blocks
basic.forever(function () {
    basic.showNumber(mbc.lineWidth())
    basic.pause(200)
})
```
