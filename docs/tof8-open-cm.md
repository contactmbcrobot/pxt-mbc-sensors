# distance 8-ch most open (cm)

Distance in cm of the most open (farthest) direction.

```sig
mbc.tof8OpenCm()
```

## Returns

* a number.

## Example

```blocks
basic.forever(function () {
    basic.showNumber(mbc.tof8OpenCm())
    basic.pause(200)
})
```
