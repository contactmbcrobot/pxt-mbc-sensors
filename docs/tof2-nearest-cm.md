# distance 2-ch nearest (cm)

The nearer of the two distances in cm.

```sig
mbc.tof2NearestCm()
```

## Returns

* a number.

## Example

```blocks
basic.forever(function () {
    basic.showNumber(mbc.tof2NearestCm())
    basic.pause(200)
})
```
